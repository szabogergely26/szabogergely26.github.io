Monitor Config – Dokumentáció

A Monitor Config egy saját használatra készült, PyQt5-alapú kijelzőprofil-váltó KDE Plasma környezethez. A program célja, hogy a laptop kijelzője, a TV és a soundbar között gyorsan, biztonságosan és ismételhetően lehessen váltani anélkül, hogy minden alkalommal kézzel kellene xrandr vagy kscreen-doctor parancsokat futtatni.

Rendszerkövetelmények és függőségek

Főbb futási függőségek:

  • Python 3
  • PyQt5
  • xrandr
  • kscreen-doctor

Debian / KDE alatt szükséges csomagok például:

sudo apt install python3-pyqt5 x11-xserver-utils libkscreen-bin

Értesítésekhez és kapcsolódó integrációhoz szükség lehet még:

sudo apt install python3-gi gir1.2-notify-0.7 libnotify-bin

A pontos függőségeket a Debian-csomag vezérlőfájlja tartalmazza.

Telepítés

A program Debian-alapú rendszeren .deb csomagból telepíthető.

Telepítés helyi csomagból:

sudo apt install ./monitor-config_*.deb

Telepítés után indítható:

monitor-config

A grafikus alkalmazás az alkalmazásmenüből is elérhető.

Profilok testreszabása

A profilok alapja az xrandr, illetve a kscreen-doctor aktuálisan érvényes kimenete. Ezt kell bemásolni a megfelelő fájlba:

  • /home/monitor-config/kscreen-input.txt
  • /home/monitor-config/xrandr-input.txt

attól függően, melyik módot használod. Ez a rész a dokumentáció legrészletesebben bővülő pontja lesz.

Eltávolítás

Mivel a program megbízhatóan nem jelenik meg a Discover szoftverközpontban, eltávolítani terminálból lehet: 

sudo apt remove monitor-config
sudo apt purge monitor-config

A purge a konfigurációs fájlokat is eltávolítja, a remove ezeket megtartja.
