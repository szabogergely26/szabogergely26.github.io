Letöltések

Az alábbi alkalmazások Debian/KDE (Linux) környezetre készültek. Ahol Release csomag érhető el, ott közvetlen .deb letöltés található; a többi projektnél egyelőre a forráskódra mutat a link, amíg elkészül a végleges APT-alapú telepítési útmutató.

Miért nincs kész Windows telepítő? Windows 11 alatt egy aláíratlan program telepítőjét a rendszer (Intelligens alkalmazáskezelés) rendszeresen letiltja, függetlenül attól, mennyire biztonságos a program maga. Ennek feloldásához fizetős digitális aláírás (code signing tanúsítvány) kellene, ami egy hobbiprojekt esetén jelenleg nem éri meg. Aki mégis szeretné használni valamelyik alkalmazást Windows alatt, a forráskódból saját maga is lefordíthatja — az adott projekt GitHub repójában, a windows_build.md fájlban lépésről lépésre útmutatót talál hozzá.
